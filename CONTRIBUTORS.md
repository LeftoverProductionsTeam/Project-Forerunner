# Contributors

## Halo and runtime foundations

- **Bungie** created Halo: Combat Evolved. **Microsoft** published the original Xbox game, and **Gearbox Software** worked with Bungie on the original Windows port. Their work and the credits in the original games underpin this project. [Microsoft's original Windows release announcement](https://news.microsoft.com/source/2003/09/30/master-chief-set-to-conquer-new-grounds-halo-for-windows-storms-store-shelves-sept-30/)
- **punpckhdq** and **bnunu** reconstructed the Xbox game source. bnunu also contributed Custom Edition map findings and the OpenCE co-op cutscene fallbacks retained in `8903981f` and `958cd833`. [punpckhdq/halo](https://github.com/punpckhdq/halo) · [bnunu/halo-1](https://github.com/bnunu/halo-1)
- **FractumSeraph** and contributors combined the OpenCE and Chupathingy histories that Forerunner builds on. Commit authorship and the inherited credits accompany that history. [Fractum foundation](https://github.com/FractumSeraph/OpenCE/tree/eae91445333bc8ebfb1604e08fcedffbd5c3a558)
- **Milenko** and the **ChupathingyCE contributors** built the port and Delta features Forerunner inherits. Forerunner reuses the project's HMV Forge codec and Milenko's Workshop path validation. [ChupathingyCE](https://github.com/ChupathingyCE/chupathingyce) · [HMV codec revision](https://github.com/ChupathingyCE/chupathingyce/tree/1b732f52d73f214d4f0068178d45753cca56dcf3)
- **OpenCE contributors** provided port, networking, co-op and game-mode foundations. **chestahh** and the **GulchCE contributors** provided inherited MCC loading, audio work and graphics fixes. [OpenCE](https://github.com/OpenCommunityEdition/OpenCE) · [GulchCE](https://github.com/chestahh/GulchCE)
- **Mota (mOTA-lEV)** and **OpenCE-Faber contributors** provided retained projectile lifetime fixes, the career-record precedent, and the Forge and Firefight work consulted for integration. The inherited career-record adaptation is credited to Mota and carries the upstream permission described in the original credits. [OpenCE-Faber](https://github.com/SutlabSol/OpenCE-Faber) · [OpenCE-Forge](https://github.com/SutlabSol/OpenCE-Forge)
- **OpenH1 contributors**, including **goatbutt**, **startupfoundry** and **pastudan**, provided inherited Xbox audio, rendering and interpolation work. Forerunner also adapted OpenH1's VR grip and input behavior through the existing runtime. [OpenH1](https://github.com/OpenH1/goath1) · [Integration and revisions](UPSTREAM_FEATURE_MATRIX.md)

- **Aerocatia** and **Jessie** supplied the credited Halo PC Restored HUD art. **ugoboom** tested high-resolution HUD compatibility. **fizzy** created Cyborg Interface Gothic, and **snapchipper** supplied controller button art. [HUD notice](port/assets/hud/NOTICE.md) · [Inherited detailed credits](README.md#credits)
- **FractumSeraph**, **MrBruh**, **ORION**, **saulob** and **pugzysixtyfour** are credited for the inherited icon, controller, HUD and cursor artwork as itemized in the original [art authors record](AUTHORS.md).
- **CMT, MMAMONSTERRR-D92209 and Teh lag** are credited for the CMT Elite FP Arms evaluated in private Black Echo builds. The archive readme names MMAMONSTERRR-D92209 and credits Teh lag. Redistribution permission is unverified. [Original listing](https://www.halomaps.org/hce/detail.cfm?fid=5764) · [Private validation record](SPARK_INTEGRATION_CONTRACT.md#first-person-arms-for-authored-characters)
- **Watanoge** extended Forge and Firefight in Halo Content Evolved, building on Mota's work. The reviewed source is a compatibility reference. [Halo Content Evolved revision](https://github.com/Watanoge/halo-content-evolved/tree/aff7a5d1b8ef592eea1106b64713e2a5d0a74569)
- **SnowyMouse** and the **Invader and Chimera contributors** provided separate CE tools and format references used in development. **Project Guilty Spark contributors** provide map authoring, asset and mission handoffs, including Black Echo. [Invader](https://github.com/SnowyMouse/invader) · [Chimera](https://github.com/SnowyMouse/chimera) · [Guilty Spark](https://github.com/LeftoverProductionsTeam/Project-Guilty-Spark)
- Our thanks also go to Halo's mod creators, tool authors, researchers, tutorial writers, testers, server operators and archivists. The [inherited credits](README.md#credits), original file notices and Git history retain the detailed contributor roster.
